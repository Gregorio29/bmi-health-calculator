# Anthropometric & Metabolic Equations Reference

## 1. Body Mass Index (BMI / IMC)
Formula:
$$\text{BMI} = \frac{\text{Weight (kg)}}{(\text{Height (m)})^2}$$

### Standard Adult Categories (WHO / CDC)
- **Underweight:** BMI < 18.5
- **Normal weight:** 18.5 ≤ BMI ≤ 24.9
- **Overweight:** 25.0 ≤ BMI ≤ 29.9
- **Obesity Class I:** 30.0 ≤ BMI ≤ 34.9
- **Obesity Class II:** 35.0 ≤ BMI ≤ 39.9
- **Obesity Class III:** BMI ≥ 40.0

---

## 2. Basal Metabolic Rate (BMR) — Mifflin-St Jeor Equation
Validated as the standard predictive equation for resting metabolic rate:

- **Men:**
$$\text{BMR} = (10 \times \text{weight in kg}) + (6.25 \times \text{height in cm}) - (5 \times \text{age in years}) + 5$$

- **Women:**
$$\text{BMR} = (10 \times \text{weight in kg}) + (6.25 \times \text{height in cm}) - (5 \times \text{age in years}) - 161$$

---

## 3. Total Daily Energy Expenditure (TDEE)
Calculated by multiplying BMR by standard physical activity multipliers:
- **Sedentary (desk work, little exercise):** 1.2
- **Light activity (1-3 days/week):** 1.375
- **Moderate activity (3-5 days/week):** 1.55
- **High activity (6-7 days/week):** 1.725
- **Very high activity (intense daily training):** 1.9
